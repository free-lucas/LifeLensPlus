## 一句话概览

每 20 秒截屏 → 相似帧过滤（32x18 灰度网格） → 截图存文件系统、活动记录与 AI 任务写 SQLite（同一事务）
→ 后台 AI Worker 调本地 Ollama 视觉模型 → 结构化结果回填 `activities` 表
→ 每 10 分钟把这一时段的记录汇总成一条活动说明写入 `time_blocks` 表，在「动态」页回看
→ 每天把这一天的区块二次汇总成一篇日记写入 `diaries` 表，在「日记」页回看
→ 「看板」页按天 / 周 / 月 / 年把这些数据画成图表
→ 后台把三层记忆（Activity / Block / Diary）嵌入成本地向量写进 LanceDB，
在「搜索」页用一句自然语言（如「我最近什么时候研究过 AI Agent？」）检索到对应的时间片段。
→ 在「问答」页直接问一句关于过去的问题（如「最近一段时间我主要在做什么？」），
系统先检索相关记忆，再由本地模型只根据这些记忆给出回答，并列出依据的相关记忆。
→ 桌面上常驻一个 56x56 的悬浮圆标（悬浮入口）：点它打开 / 聚焦主界面，
关掉主界面它还在（关闭 = 隐藏，后台截图与 AI 链路照常跑），右键弹出「打开主界面 / 暂停-恢复录制 / 退出应用」，
并且对真实事件给出视觉反馈：小镜（镜头宝宝）平时就待在球上，录制中它跟着一起动、暂停时整球暗下来并冻住、
截图一瞬间快门闪光、AI 分析成功闪绿并画一个对勾、出错时红闪一下 ——
三个瞬时态由小镜（镜头宝宝）上场演：截完图得意一下、分析成功换成笑脸、出错时一脸疑惑。

## 快速开始

```bash
npm install      # Electron + @lancedb/lancedb；SQLite 用 Node 内置的 node:sqlite
npm start        # Electron 应用
npm test         # node --test，Ollama 全部 mock，不需要 GPU（LanceDB 用真实的本地文件）
```

## 数据落地位置

| 数据 | 位置 |
| --- | --- |
| 活动记录、AI 任务队列 | `<LIFELENS_DIR>/lifelens.db`（SQLite，WAL 模式） |
| 截图原图 | `<LIFELENS_DIR>/<YYYY-MM>/images/<YYYY-MM-DD_HH-mm-ss-SSS>.png` |
| 语义索引（向量） | `<userData>/lancedb/`（可随时重建，删掉不影响原始数据） |
| 悬浮入口位置 | `<userData>/launcher-position.json`（只有 `{ x, y }`，删掉就回到主屏右下角） |

`LIFELENS_DIR` 默认是系统「图片」目录下的 `LifeLensPlus`。
