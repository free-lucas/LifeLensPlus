# 小镜第 4 态：待机（Idle）

[32-小镜表情动画](32-小镜表情动画.md) 定义的是小镜的**三态表情**，三只都只在瞬时特效里露面。
这份文档记录第 4 只 —— **待机**态：它补上了素材目录里一直没做完的那只，
回答「小镜不说话的时候长什么样」。

> **状态：已接入悬浮入口**（Phase 13.4 起是悬浮球的**默认脸** —— 录制中与暂停时都在台上，见第 5 节）。
> Figma 生成式插件里的第 4 态还没补，原因见第 6 节。

## 1. 它是从哪里来的

`src/renderer/assets/mascot-idle.svg` 原来是一张**没画完的草图**：

| 症状 | 说明 |
| --- | --- |
| 没有任何 SMIL | 0 个 `<animate>`；另外三只分别有 8 / 11 / 13 个 |
| 根节点残留 `class="glyph"` | 那是悬浮球上光圈图标的类名，复制过来没删 |
| 没人引用 | `launcher.html` 只内联了三只，`launcher.js` 的 `EFFECT_MASCOTS` 也只有三态 |
| 只有 2939 字节 | 另外三只是 4.9 ~ 6.3KB |

而它的 `aria-label` 一直写着「LifeLens 小镜 · 待机」—— 位置和意图都很清楚，只是没做完。
这次按家族骨架把它补成一只成品，现在有 5029 字节、8 个 `<animate>`（与 `smug` 同数）。

## 2. 表情：它待机时是什么样

| 部位 | 待机态 | 与另外三态的关系 |
| --- | --- | --- |
| 眼 | 一对**下垂的半闭眼**（`M65.98 90.5 C61 118.5 99 118.5 94.02 90.5 Z`），瞳孔在眼内缓慢下沉 | 独有；得意是实心瞳孔 + wink、思考在扫视、开心是月牙眼 |
| 眉 | **没有眉毛** | 独有；得意外挑、思考一高一低 |
| 嘴 | 一条很浅的抿嘴 `M91 129 Q100 137 109 129` | 独有；思考是 w 形、开心是张嘴笑 |
| 腮红 | 浓度 `0.22`（四态里最淡） | 得意 0.42 / 思考 0.26 / 开心 0.6 |
| 头部标记 | 右上角一枚 **z**（`translate(150 54)`），透明度 `0.3 ↔ 0.8` 脉动并上下浮动 6px | 独有；它顶替了另外三态各自的「事件标记」——快门、扫描带、对勾徽章 |

z 是「睡着了 / 没在忙」的通用符号，正好和「待机」对上。

## 3. 动效参数（家族里最慢的一档）

共用的骨架一个都没改，只把节奏调到最慢：

| 动效 | 待机 | 得意 | 思考 | 开心 |
| --- | --- | --- | --- | --- |
| 轨道环旋转 | **22s** | 14s | 5.5s | 10s |
| 上下浮动 | `0 6; 0 -2; 0 6` / 5.4s | 2.6s | — | — |
| 天线摆动 | `±2°` / 5.2s | 9° / 1.6s | 4° / 3.4s | 15° / 0.9s |
| 瞳孔下沉 | `0 0; 0 1.8; 0 0` / 5.2s | — | 扫视 | — |
| 腮红浓度 | 0.22 | 0.42 | 0.26 | 0.6 |
| z 标记 | 浮动 5.2s + 透明 5.2s | — | — | — |

**没有改的**：整球呼吸（`1 → 1.018` / 4.2s）、天线杆与顶球、光晕、球体温差渐变、
镜片高光、轨道环 `r 86` / `dasharray 4 9` —— 这些四态共用。

## 4. 与家族规范的符合性（实测）

| 检查 | 结果 |
| --- | --- |
| XML 合法、无 BOM、以 `<svg ` 开头 | 通过 |
| 根节点与另外三只同构（`role="img"` + `aria-label`） | 通过 |
| DOM 骨架元素数 | 64，与 `smug` **完全一致** |
| 8 个 `<defs>` 的 id 唯一且全部带 `-idle` 后缀 | 通过 |
| 硬约束 2「被 `<animate>` 覆盖的属性必须写基础值、且等于首帧」 | 逐个核对：待机态被动画覆盖的属性只有天线顶球的 `r` 与 z 标记的 `opacity`，两处都写了等于首帧的基础值（`r="4.6"` 对 `4.6;6.6;4.6`、`opacity="0.3"` 对 `0.3;0.8;0.3`） |
| 硬约束 3「整球呼吸要 `translate(100 100)` 外套 + `translate(-100 -100)` 内衬」 | 照抄家族写法 |
| 四态并排渲染 | 视觉一致（验证方式见第 7 节） |
| `node --test test\launcherMascot.test.js` | 6/6 通过（新增两条：素材与内联副本逐行一致、它只在两个 `state-*` 下上场且瞬时态时退场） |
| `node --test test\launcherView.test.js` | 17/17 通过（新增两条：暂停时放开时间轴、与瞬时态互不干扰） |
| 真实 Electron 冒烟 `test\smoke\launcherMascotSmoke.cjs` | PASS 34 / FAIL 0（其中「待机 1~11」全过） |

`<defs>` 里有 4 个 id（`head-idle` / `eyel-idle` / `mouth-idle` / `scan-idle`）没有被引用。
这**不是**本次引入的问题：`smug` 有 3 个、`happy` 有 4 个未引用 id，它们来自插件模板固定输出的那一套。
四只一致，所以留着比删掉更符合「与插件模板保持同构」。

## 5. 怎么接进悬浮入口（默认脸）

接入点只有一个：悬浮入口的 `body.state-*`。从 **Phase 13.4** 起，待机小镜是悬浮球的
**默认脸** —— 录制中与暂停时都在台上，只有三个瞬时态（快门 / 成功 / 出错）时才让位。
（Phase 13.3 最初只在暂停时上场，13.4 改成默认脸，原因与代价见
[36-变更记录-Phase13.4](36-变更记录-Phase13.4.md)。）

**「在不在录」的信号不靠这张脸**，靠三样别的东西：

| 信号 | 录制中 | 暂停 |
| --- | --- | --- |
| 球体亮度 / 饱和度（`.ball` 的 `filter`） | `none`：亮 | `brightness(0.62) saturate(0.72)`：暗、去饱和 |
| 外围那圈扫光（`.ball::before`） | 在转（5s 一圈） | `animation-play-state: paused` |
| 小镜自己的 SMIL 时间轴 | 在演 | 冻在第 0 帧 |

最后一条正是 Phase 13.1 定下的「一暂停整个圆标完全静止」。脸换成小镜以后这条要保住，
所以时间轴的方向与 13.3 相反 —— **录制中放开、暂停冻住**（`launcher.js` 的 `applyState`）。

四处改动：

| 改动 | 位置 |
| --- | --- |
| 内联第 4 份 SVG（与素材逐行一致） | `src/renderer/launcher.html` |
| 两个 `state-*` 下 `.mascot-idle` 显出来、`.glyph` 让位 | `src/renderer/launcher.css` |
| 三个瞬时态下 `.mascot-idle` 退场（见下） | `src/renderer/launcher.css` |
| 加载时把它一并冻住；`applyState` 里录制中放开、暂停冻回 | `src/renderer/launcher.js` |

**为什么不能用 `mascot-pop`**：那条瞬时态的出场动画最后一帧是 `opacity: 0`
（瞬时态靠 class 回收，本来就该演完自己消失）。默认脸没有「演完」这回事，用它会 0.5 秒后自己消失。
所以另写一条 `mascot-in`：基础值 `opacity: 1`，动画只负责淡入那一下，
`animation-fill-mode` 默认 `none`，动画结束回到基础值 = 停在可见状态。

**台上来了瞬时事件怎么办**：录制中自不必说，暂停也只是「不再截图」——
AI 队列里已经排着的任务照样跑完，`analysis`（分析写完）甚至 `error` 照样会到。
两只小镜都铺满整颗球，叠在一起会互相打架 —— 所以有瞬时态时**让待机这只退场**，
把球让给那只来报信的：

```css
body.effect-shutter .mascot-idle,
body.effect-success .mascot-idle,
body.effect-error .mascot-idle { visibility: hidden; opacity: 0; }
```

这条与放它出来的那条**特异性相同**（都是 0,2,1），所以**书写顺序就是优先级**：
它在后面，才压得住。瞬时态 `animationend` 回收 class 之后待机小镜自动回到台上
（时间轴没被动过，接着演）。`test/launcherMascot.test.js` 的「小镜 6」把这条顺序也钉住了。

**时间轴归谁管**：

```text
applyState(running)
  running === true   -> playMascot(idle)     setCurrentTime(0) + unpauseAnimations() （录制中：在演）
  running === false  -> freezeMascot(idle)   pauseAnimations() + setCurrentTime(0)    （暂停：全静止）
```

`prefers-reduced-motion` 下 `playMascot` 直接返回：小镜停在第 0 帧不演，
CSS 那边也把淡入去掉（`animation: none`）。这里可以放心删动画 ——
待机小镜的显隐是纯 CSS 的，不像瞬时态那样靠 `animationend` 回收 class，删掉动画不会把 class 卡住。

实测（真实 Electron 冒烟）：录制中它确实在演（0.2s → 0.717s）、圆标让位（`glyph=0`）；
暂停后冻回第 0 帧、但仍然在台上；瞬时事件插进来时那只瞬时态小镜上场（`smug=visible`）、
**待机这只退场**（`idle=hidden`），两者不会同时显形。

## 6. Figma 侧的缺口

家族的**源头**是 Figma 生成式插件「LifeLens 小镜表情动画」
（见 [32-小镜表情动画](32-小镜表情动画.md) 第 7 节），它的 `StateId` 目前只有
`'smug' | 'thinking' | 'happy'` 三态。要让它也能生成待机态，需要动这些地方：

- `code.ts` —— `StateId` 加 `'idle'`；`STATES` 加待机条目；
  `ORBIT_DUR` / `BLUSH_OPACITY` / `ANTENNA` / `FLOAT` 四个 Record 各加 `idle` 一项；
  `buildMascot` 加 idle 分支（下垂眼 / 抿嘴 / z 标记）；看板标题与宽度跟着四态改
- `ui.html` —— 下拉选项加「待机」（**顺序必须与 `STATES` 下标对齐**）、`PLAY` 数组加一档

**这一步这次没做成**：Figma MCP 被套餐限流了（Starter 计划 20 次/月已用完），
所有 Figma 工具（含 `use_figma` / `get_screenshot`）都返回同一条限流错误。
恢复额度后按上面的清单补即可 —— 这份 `mascot-idle.svg` 就是 `buildMascot` 该产出的精确形状，
可以拿它反推 idle 分支。

## 7. 怎么验证

```powershell
# 1. 家族规范（素材与内联副本是否一致、id 是否唯一、CSS 规则是否齐）
node --test test\launcherMascot.test.js

# 1b. 默认脸 + 持续态的完整行为链（真实 Electron：class、时间轴、瞬时态优先、降级）
node_modules\electron\dist\electron.exe test\smoke\launcherMascotSmoke.cjs
# -> 「待机 1~11」：录制中在台上且在演 / 圆标让位 / 三只瞬时态仍冻着 /
#    暂停时冻回第 0 帧 / 瞬时事件插进来时瞬时态上场且待机退场 / 恢复后回到台上

# 2. 目视：把四只并排丢进一个深色页面，用无头 Edge 截图
& "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --headless=new --disable-gpu `
  --hide-scrollbars --virtual-time-budget=2500 --window-size=1080,300 `
  --screenshot=out.png "file:///<四态并排的 html 路径>"
```

实测结论：四只并排时，待机态的下垂眼、淡腮红、右上角 z 都清楚，构图与另外三只同比例，
和原来的光圈圆标是同一套视觉语言。
