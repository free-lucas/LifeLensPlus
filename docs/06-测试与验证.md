注意点（本次踩到的坑）：

- **全局作用域冲突**：`renderer.js` 与 `timeline.js` 都是 classic script，共享全局作用域，
  重名的函数声明会互相覆盖（`renderer.js` 与 `timeline.js` 都有 `pad` / `formatClock`）。
  因此 `timeline.js` 整体包在 IIFE 里；`test/timelineView.test.js` 有一条用例专门守着这件事。
- **CSP 会拦内联事件处理器**：`script-src 'self'` 下不能用内联 `onerror`，缩略图失败回退必须用
  `addEventListener('error')`。
- 同 Phase 7.1：本机已有 LifeLensPlus 在运行时单实例锁会挡住新实例，用 `--user-data-dir` 指向独立目录即可。

更完整的变更说明见 [12-变更记录-Phase7.2](12-变更记录-Phase7.2.md)。
