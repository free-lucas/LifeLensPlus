# 小镜（镜头宝宝）三态表情动画

设计资产迭代，不涉及截图 / AI / SQLite / LanceDB 任何业务链路，也不新增运行时依赖。
产物是一个 **Figma 生成式插件**：它在 Figma 里按参数生成三套带 SMIL 动画的 SVG，
既能看动效、也能一键复制源码或铺到画布上。

「小镜」= 镜头宝宝：一颗深色玻璃球，套着青蓝→蓝紫的霓虹虚线轨道，头顶一根小天线，
脸上两坨腮红。三态对应录制链路上最需要被看见的三件事：**刚截完图、正在分析、分析成功**。

> 还有第 4 只：**待机**态。它不属于这三个瞬时态，是另有的一只，见 [34-小镜待机态](34-小镜待机态.md)。

## 1. 三态与触发事件

| state | 表情 | 接入的触发事件 | 动效要点 | 主要周期 |
| --- | --- | --- | --- | --- |
| `smug` | 得意 | `record`（刚截完一张图） | 快门光圈从镜片内缘向外炸开并淡出；左眼实心瞳孔 + 高光 + 一道斜光；右眼 wink；嘴角挑起；眉毛外挑 | 快门 1.8s / 浮动 2.6s / 轨道 14s |
| `thinking` | 思考 | `error`（出错，先借用） | 瞳孔上移并左右扫视；眉毛一高一低；w 形嘴；扫描带在球体内上下巡游；三个思考气泡依次亮起；轨道提速并叠一圈反向紫色细环 | 扫描 3.4s / 轨道 5.5s / 反向环 3.6s |
| `happy` | 开心 | `analysis`（AI 结果写回） | 月牙笑眼；张嘴笑 + 粉舌头；绿色对勾徽章挂在轨道上；三颗四角星闪烁；整只球连跳两下 | 弹跳 1.6s / 轨道 10s / 天线 0.9s |

三态共用一套「呼吸」（整体缩放 1 → 1.018，4.2s）与一根天线，只按状态改摆幅与频率：
得意 9°/1.6s、思考 4°/3.4s、开心 15°/0.9s。

Phase 13.2 已经把它接到了 `docs/30-悬浮窗特效.md` 的三个瞬时态上：`record` → 得意、
`analysis` → 开心、`error` → 思考。原本设想的是「思考」对「分析中」，但 launcher 目前只收得到
`status.running`（= 正在录制），收不到「AI 队列非空」这个信号，所以三态里先由 `error` 借用
「思考」—— 一个 0.5 秒的红闪配「小镜一脸疑惑」读起来是「咦？」，说得通，但真要做出错态还是
得回插件补第四只。

## 4. 三条硬约束（写动效前先看）

1. **每个动效元素的第一帧都必须是构图完整的可见状态。** 动画只负责循环演出。
   这样同一份 SVG 既是动画、也是一张能直接看的静态图，导入 Figma 时也不会出现
   「只在动画里才存在」的空元素。
2. **被 `<animate>` 覆盖的属性同时写基础值，且基础值等于动画第一帧。**
   SMIL 不跑（或被转成静态矢量）时画面依然成立。
3. **`type="scale"` 默认绕 `(0,0)` 缩放。** 整只球要绕球心呼吸，必须用
   `translate(100 100)` 外套 + `translate(-100 -100)` 内层夹住，否则整只往左上角跑。

## 5. 三个已经踩过的坑

| 坑 | 现象 | 现在怎么做的 |
| --- | --- | --- |
| 竖直线段用 `objectBoundingBox` 渐变 | 天线杆整根不渲染（退化包围盒宽度为 0，渐变不产生像素），三态头顶只剩一个孤球 | 杆改用纯色 `#9df6ff`，渐变只用在圆/矩形等非退化图形上 |
| 对勾用 `stroke-dashoffset` 生长 | 生长动画第一帧只有一小截，静态帧读成一根「绿棒」 | 对勾恒定完整可见，改成徽章光环做 `r` + `opacity` 脉冲 |
| 扫描线写成硬边矩形 | 静态帧像玻璃上的一道划痕 / 接缝，动起来也糊 | 换成「上缘渐隐的柔光带 + 一条细亮线」，并裁切在球体轮廓里 |

## 7. 怎么接进 Electron 渲染层

**结论：内联，不要用 `<img>`。** Phase 13.2 已经按这条路把悬浮入口接上了。

```text
src/renderer/assets/mascot-{smug,thinking,happy}.svg   素材（源）
  -> src/renderer/launcher.html                        原样内联，各包一层 span.mascot
       src/renderer/launcher.css                       显隐 + mascot-pop / mascot-fade
       src/renderer/launcher.js                        SMIL 时间轴的放开与冻结
```

`<img>` 这条路在本仓库走不通，三个理由：

| 理由 | 说明 |
| --- | --- |
| CSP | `launcher.html` 是 `default-src 'none'` 且没有 `img-src`，`<img>` 走兜底被直接拒掉 |
| 重播 | `<img>` 里的 SMIL 自己从头循环，没有任何办法在「事件到来那一刻」把它拨回第一帧 |
| 可控性 | 内联之后 `<svg>` 是真实 DOM 节点，才能调 `setCurrentTime()` / `unpauseAnimations()` / `pauseAnimations()` |

内联的代价是同一份图形有两个落点，所以 `test/launcherMascot.test.js` 会逐行比对
assets 与 HTML 里的副本 —— 只改了一边，`npm test` 直接红。

**每次触发都从第一帧开始**是这么做到的（`src/renderer/launcher.js`）：

```js
// 出场：先拨回 0，再放开
svg.setCurrentTime(0);
svg.unpauseAnimations();
// 演完：停住 —— 看不见的时候不该还在跑时间轴
svg.pauseAnimations();
svg.setCurrentTime(0);
```

SMIL 没有 `animationend`，所以「什么时候该冻回去」由光圈那条 CSS 动画的 `animationend`
决定，小镜的出场动画时长因此必须与它对应的光圈一致。页面加载时三只全部先冻在第 0 帧，
藏着的 SVG 不空转。

尺寸完全交给 CSS（`.mascot > svg { width: 100%; height: 100% }`），
SVG 里 `width` / `height` 两个属性只是给单独打开这份素材时用的默认值。

## 8. 怎么验证

- 插件侧：把 `code.ts` 拿到 Node 下跑（`node --experimental-strip-types`）——
  用一组 mock 的 `figma` 全局对象驱动 `ready` / `insert` 两条消息，导出三张 SVG
  并断言 `insertDesign` 能跑通（尺寸兜底、CJK 字体、画板子节点、relaunch data）。
- 视觉侧：用 Electron 开一个无窗口的 `BrowserWindow` 渲染 SVG，截图前先
  `svg.pauseAnimations()` + `svg.setCurrentTime(0)` —— 冻到的正是 Figma 导入静态矢量
  时看到的那一帧，可以拿它检查「首帧是否构图完整」。
- 换算关系：`viewBox 200` 下 1 单位 ≈ 显示尺寸的 `1/200`，所以在 64px 下要确认
  五官仍可辨认（当前最小可用尺寸按 64px 设计）。
