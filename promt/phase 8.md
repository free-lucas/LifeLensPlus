添加下列功能：
每十分钟，汇总一下十分钟内所有的记录，结合上一个十分钟的分析结果。如果有之前还没处理过的十分钟时间段，在应用运行的时候，排队处理，在 UI 上显示一个汇总中的标记。汇总需要结构化的输出下列内容：
1.1 用户正在做的项目名称，包含游戏名、电视剧名、开发的软件名、写的文章名等（如果和上一个 10 分钟一样，请用相同的名字）。比如 “玩《荒野大镖客》”、“写《2026 年中报告》”
1.2 用户当前行为的分类：娱乐、工作、学习、社交
1.3 具体的描述信息，1000 字左右。
1.4 有使用到的软件列表
1.5 可能遗漏的重要待办事项，可以为空。
在当前 UI 上，增加一个标签页，名字为 “动态”。包含下列内容：
2.1 一个类似 github 的热力图，显示最近的几十个点，每个点表示 10 分钟。用不同颜色表示不同活动类型。选中每个点，可以查看当时的活动。
2.2 显示一个 timeline，可以纵向滑动加载，显示在做的项目名称和具体描述信息。还有列出所有用到的软件，用 tag 的形式。
2.3 可以根据项目名称、软件、时间的方式，筛选 timeline。
